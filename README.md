# Real-Time Speech-to-Text Application

## Description
A web application that converts speech into text in real time and stores transcription history in a PostgreSQL database.

## Technologies
- **Frontend:** Angular, TypeScript
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL

## Features
- Real-time speech transcription
- Multilingual support (if configured)
- Save and view transcription history

## How to Run

**Backend**
```bash
cd backend
mvn spring-boot:run
```

**Frontend**
```bash
cd frontend
npm install
npm start
```

Open `http://localhost:4200` in your browser.
